# Dorothea website

Static website for **Dorothea — Private Home & Lifestyle Concierge**.

## Included
- `index.html`
- `styles.css`
- `script.js`
- `assets/dorothea-logo.png`
- `assets/dorottya-founder.jpeg`

## Before publishing
Open `script.js` and add:
- your WhatsApp number in international format, digits only
- your final Dorothea business email address

## GitHub Pages
1. Upload all files and the `assets` folder to the root of your `dorothea-website` repository.
2. Commit the files.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will show the public website URL after deployment.

## Notes
The website uses the real founder portrait and the supplied Dorothea logo.
The two large lifestyle photos are loaded remotely from Unsplash.
